# 코레일 빈자리 감시 + 텔레그램 알림

크롬에 열어 둔 코레일 예매 화면을 **새로고침(F5)하며 지켜보다가**, 감시 중인 버튼 4개(예: 열차1/열차2 ×
일반실/특실) 중 하나라도 매진이 아니게 되면 그 버튼을 클릭하고, 이어서 **예약 버튼**을 클릭한 뒤
**텔레그램으로 알려주는** 프로그램입니다. 결제와 예약 확정은 직접 하세요.

> 버튼 4개가 **동시에** 매진 아니게 되면, 준비 작업에서 지정한 **1~4번 순서 중 가장 앞선 버튼**을
> 자동으로 클릭합니다. 원하는 열차·좌석을 1번으로 지정해 두세요.

> ⚠️ 코레일 이용약관은 자동 프로그램 사용을 제한할 수 있습니다. 새로고침 간격을 너무 짧게 하지 말고,
> 본인 책임하에 사용하세요.

## 1. 텔레그램 준비 (한 번만)
1. 폰(또는 PC)에 텔레그램 설치 후 가입
2. 텔레그램 검색창에 `BotFather` 검색 (파란 체크 표시가 있는 공식 계정)
3. `/newbot` 입력 → 봇 이름 입력 → 봇 아이디 입력(끝이 `bot`으로 끝나야 함)
4. 알려주는 긴 글자(**토큰**)를 복사해 두기 — 남에게 보여주면 안 됩니다
5. 방금 만든 봇을 검색해서 들어가 **"안녕"** 이라고 메시지 보내기

> 텔레그램 연결만 먼저 따로 해두고 싶다면(마우스로 영역 지정하는 단계 없이):
> **`setup_telegram.bat` 더블클릭** (또는 `python setup_capture.py --telegram`)

## 2. 준비 작업 (한 번만)
PowerShell 또는 터미널에서 이 폴더로 이동해서:
```
pip install -r requirements.txt
python setup_capture.py
```
- 텔레그램을 아직 연결 안 했다면 `y`를 눌러 여기서 같이 연결할 수 있습니다 (토큰 붙여넣으면 자동 연결 + 테스트 메시지 전송).
  이미 `--telegram`으로 먼저 연결했다면 `n`을 누르면 됩니다.
- **크롬에 감시할 버튼 4개가 전부 '매진'인 화면을 열어 두세요.**
- 이 검은 창은 크롬의 지정 영역을 **가리지 않도록 구석으로** 옮겨 두세요.
- 안내에 따라 마우스로 6곳을 지정합니다. (6초 안에 마우스를 해당 모서리에 올려두면 됩니다)
  1. 기준 칸 (같은 줄의 출발 시간처럼 항상 보이는 글자 — 화면이 정상인지 확인하는 용도)
  2~5. 버튼 1~4번의 '매진' 표시 칸 (예: 열차1 일반실 / 열차1 특실 / 열차2 일반실 / 열차2 특실)
     - **동시에 여러 버튼이 풀리면 번호가 빠른 쪽이 자동으로 클릭됩니다.** 원하는 조합을 1번으로 지정하세요.
  6. 예약 버튼 (버튼 클릭 뒤 이어서 누를 '예약' 버튼 위치)

> 이미 준비 작업을 마친 경우:
> - 예약 버튼 영역만 다시 지정하려면 **`setup_reserve_click.bat` 더블클릭**
> - 영역 위치는 그대로 두고 **그림만 다시 찍으려면 `setup_recapture.bat` 더블클릭**
>   (판정이 이상하게 나올 때 먼저 시도해 보세요. 버튼 4개가 전부 '매진'인 화면에서 실행해야 합니다.)

## 2-1. (선택) 예약 후 안내 팝업 자동 확인
예약 버튼을 누른 뒤 "이용안내" 같은 팝업이 **가끔** 뜨는 화면이라면, 이 팝업의 '확인' 버튼까지 자동으로
눌러주도록 설정할 수 있습니다. (설정 안 해도 프로그램은 정상 작동합니다 — 팝업이 없는 화면이면 그냥 건너뜀)

1. 코레일 화면에서 실제로 예약 버튼을 눌러 **그 팝업이 뜬 상태**를 만드세요.
2. **`setup_popup_click.bat` 더블클릭**
3. 안내에 따라 마우스로 2곳을 지정합니다: 팝업에서 항상 보이는 글자 부분(기준 칸) → 팝업의 '확인' 버튼
4. 지정 끝나면 5초 뒤 캡처되니, 그동안 팝업이 뜬 상태로 두세요.

이후 실제 실행 시, 예약 버튼을 클릭하고 나서 잠깐(기본 1초) 기다렸다가 이 팝업이 떠 있으면 자동으로
'확인'까지 누릅니다. 팝업이 안 뜨면 그냥 넘어갑니다.

## 3. 연습 실행 (꼭 먼저 해보세요)
```
python watcher.py --dry-run
```
F5도 클릭도 하지 않고 3초마다 `판정=soldout` 처럼 표시만 합니다.
매진일 때 `soldout`이 나오면 정상입니다. (`unknown`이면 영역을 다시 지정하세요)

## 4. 실제 실행
```
python watcher.py
```
- 시작 후 5초 안에 **크롬 예매 화면을 맨 앞**으로 가져오세요.
- F5 → 0.5초마다 '기준 칸'이 보이는지 확인 → 보이면 0.9~1.3초(랜덤) 뒤 화면 판단 → 4개 버튼 전부 매진이면 30~60초(랜덤) 기다렸다가 다시 F5, 이렇게 반복합니다.
- F5 후 60초가 지나도 기준 칸이 안 보이면 텔레그램으로 알리고 멈춥니다.
- 매진 아닌 버튼이 하나라도 뜨면 (여러 개면 앞 순서 버튼): 그 버튼 안 무작위 위치 클릭 → 0.5~1.5초 뒤
  예약 버튼 안 무작위 위치 클릭 → (안내 팝업 설정을 해뒀다면 팝업 확인까지) → 텔레그램 알림 → 종료
  (모든 시간 간격은 `시간설정.json`에서 바꿀 수 있습니다. 아래 "시간 바꾸기" 참고)

## 시간 바꾸기
`시간설정.json`을 메모장으로 열어 숫자를 고치고 저장한 뒤, 프로그램을 다시 실행하세요. 단위는 초입니다.

| 항목 | 의미 | 기본값 |
|---|---|---|
| `start_delay` | 프로그램 시작 후 첫 F5까지 기다리는 시간 | 5 |
| `load_check_interval` | F5를 누른 뒤 '기준 칸'이 보이는지 확인하는 간격 (안 보이면 이 간격으로 계속 다시 확인) | 0.5 |
| `after_load_delay` | 기준 칸이 보인 뒤 매진 판단까지 랜덤 대기 (min~max) | 0.9~1.3 |
| `load_timeout` | F5 후 이 시간이 지나도 기준 칸이 안 보이면 텔레그램 알림 후 중지 | 60 |
| `wait_seconds` | 매진으로 판단한 뒤 **다음 F5를 누르기까지** 랜덤 대기 (min~max). 새로고침 간격 | 30~60 |
| `recheck_delay` | 예약 가능 발견 후 재확인까지 대기 | 2 |
| `mouse_move_duration` | 마우스가 클릭 위치까지 이동하는 시간 (랜덤) | 0.4~1.0 |
| `pre_click_pause` | 이동 후 클릭 직전 멈춤 (랜덤) | 0.1~0.3 |
| `second_click_delay` | 첫 번째 클릭과 두 번째 클릭 사이 (랜덤) | 0.5~1.5 |
| `chrome_retry_delay` | 크롬이 맨 앞이 아닐 때 다시 확인하기까지 | 5 |
| `dry_run_interval` | 연습 실행(`--dry-run`)에서 판정 간격 | 3 |
| `capture_delay` | 준비 작업에서 영역 지정 후 캡처하기까지 대기 | 5 |
| `popup_check_delay` | (선택 기능) 예약 버튼 클릭 후 안내 팝업이 떴는지 확인하기까지 대기 | 1 |

숫자 뒤의 쉼표(,)와 따옴표(")는 지우지 마세요. `min`은 `max`보다 작거나 같아야 하며, 잘못 쓰면 프로그램이 시작할 때 어디가 문제인지 알려 줍니다.

### 멈추는 방법
- **Esc 키** (최대 0.2초 안에 반응)
- 마우스를 **화면 모서리**로 세게 밀기

### 자동으로 멈추는 경우 (텔레그램으로 알려줌)
- 화면이 이상해서 5번 연속 판단 불가 (로그인 풀림, 오류창, 창 위치 변경 등)
- F5 후 60초가 지나도 화면(기준 칸)이 뜨지 않음
- 크롬이 맨 앞 창이 아닐 때는 F5를 누르지 않습니다 (다른 프로그램에 F5가 눌리는 것 방지)

## 주의사항
- 실행 중에는 **PC 절전/화면 잠금이 꺼져 있어야** 합니다. (설정 → 시스템 → 전원)
- 크롬 창 크기/위치, 화면 배율(확대)을 바꾸면 다시 `setup_capture.py`를 해야 합니다.
- 실행 기록은 `watcher.log`에 남습니다.
- `config.json`에는 봇 토큰이 들어 있으니 다른 사람에게 보내지 마세요.
- F5 후 "양식 다시 제출" 같은 창이 뜨는 화면이라면 판단 불가로 멈춥니다. 이 경우 알려주세요.
